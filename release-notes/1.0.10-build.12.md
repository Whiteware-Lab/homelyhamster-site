Prima beta Android firmata per la distribuzione diretta di Homely Hamster.

- APK release 1.0.10, build 12, con certificato di distribuzione dedicato.
- Fingerprint SHA-1 e SHA-256 registrati in Firebase; configurazione Google aggiornata per il certificato release.
- Verifica automatica di firma APK, package, versione e corrispondenza del certificato Google prima del packaging.

### Installazione e aggiornamenti

Scarica l'APK sul telefono e aprilo per installarlo. Android può chiedere
di consentire l'installazione dalla sorgente usata per scaricarlo.
La firma sarà conservata per consentire i prossimi aggiornamenti della beta.

Le precedenti build debug hanno una firma diversa: Android non permette
di aggiornarle direttamente con questo APK. Prima di rimuovere una build
debug, conserva playlist, file audio e sessioni locali. I file locali e
le credenziali conservate solo sul dispositivo non sono un backup cloud.
Le prossime build firmate con questo stesso certificato saranno aggiornabili
normalmente, purché il numero build aumenti.

### Verifiche e limiti

Il controllo della configurazione Google non sostituisce una prova di accesso
con un account reale sul telefono. Le prove fisiche con rullo e sensori restano
necessarie. OAuth Intervals.icu non ancora attivo: è disponibile la chiave API
personale. La beta Windows resta disponibile separatamente nella build 11.

Il pacchetto e i checksum sono negli allegati. L'app non installa
automaticamente gli aggiornamenti.
